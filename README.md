## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/SontuCoder/sonx-portfolio.git
cd sonx-portfolio
bun install
```

Start the development server:

```bash
bun dev
```

Open **http://localhost:3000** in your browser.

Build for production:

```bash
npm run build
npm run start
```
