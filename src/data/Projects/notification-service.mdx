# Overview

production-ready notification microservice that delivers Email, SMS, and Push Notifications through asynchronous processing. It solves delivery delays, transient failures, and unreliable message handling using background workers, retry mechanisms, and reusable templates. Built to support scalable, reliable, and consistent notification delivery across multiple channels.

## Features

- **Multi-Channel Notifications** — Send Email, SMS, and Push Notifications through a unified service.
- **Asynchronous Processing** — Handle notification tasks in background workers to keep API responses fast.
- **Retry Mechanism** — Automatically retry failed deliveries caused by temporary errors.
- **Scheduled Notifications** — Schedule reminders and alerts for future delivery.
- **Reusable Templates** — Generate consistent, personalized messages using dynamic templates.
- **User Preferences** — Customize notification channels and settings based on user preferences.
- **Delivery Tracking** — Monitor notification statuses and capture errors for easier debugging.

## Challenges

- Implementing retry logic without duplicate deliveries.
- Designing reusable notification templates.
- Processing notifications asynchronously.

## Highlights

- Reduced notification latency using background workers.
- Designed a reusable template engine.
- Implemented retry logic with exponential backoff.
